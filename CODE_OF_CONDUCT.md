# Code of Conduct

We want this project to be a welcoming, harassment-free space for everyone.

**Expected:** be respectful and constructive, assume good intent, accept feedback gracefully, focus on what is best for the project and community.

**Not acceptable:** harassment, discrimination, insults, personal attacks, doxxing, sexualized language or imagery, and other conduct that would be inappropriate in a professional setting.

Maintainers may remove or edit contributions and restrict participation that violate this code. Report concerns privately to the maintainers through GitHub (repository "Security" tab → private report, or a direct message to a maintainer).
This code is inspired by the Contributor Covenant (<https://www.contributor-covenant.org>).
