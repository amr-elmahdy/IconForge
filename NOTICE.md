## Icon source
IconForge fetches icons from [theSVG](https://thesvg.org) (<https://github.com/glincker/thesvg>) through its public registry and file URLs.
theSVG's repository code is MIT-licensed, but its README states that individual brand icons remain the property of their trademark holders,
and the catalog mixes several licenses (the registry's `license` field contains values such as `CC0-1.0`, `MIT`, `Apache-2.0`, `CC-BY-4.0`, `CC-BY-ND-2.0`, `brand-use`, `Fair Use`, `Unknown`, free text, or nothing).

## What IconForge does and does not do
- It records the `license` string exactly as the registry reports it (or `null`) and always sets `licenseVerified` to `false`. It does **not** verify licenses.
- It does not assume an icon is MIT-licensed because the source repository's code is.
- Some licenses restrict modification (for example CC-BY-ND-2.0 for AWS architecture icons). IconForge's processing (whitespace/comment cleanup, optional SVGO) changes file bytes, though it aims not to change the visual result. Check each icon's license before redistributing processed files.
- Brand names, logos and trademarks belong to their respective owners. Follow each brand's usage guidelines (`guidelinesUrl` in metadata when the source provides one).

You are responsible for complying with the license and trademark terms of every icon you use.
