# output/

Generated by `iconforge build`. Safe to commit or to copy into another project.

- `icons/` – flat folder of SVG files: `<slug>.svg` for the default variant, `<slug>-<variant>.svg` for the others.
- `metadata/icons.json` – full per-file metadata (source facts, colors, hashes, processing flags).
- `metadata/manifest.json` – lightweight entry point: slug → variants → filename + sha256.

Files are written atomically and only when their content changes. IconForge never deletes files here.
